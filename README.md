Прогноз товарообігу мережі
Опис проєкту : метою проєкту є підготовка датасету для прогнозування товарообігу мережі на 18 місяців вперед.

Структура даних :

Основною таблицею є Dataset, яка містить інформацію про товарообіг та маржинальність.

До Dataset приєднано довідники:

Categories – інформація про категорії товарів;
Stores – інформація про магазини мережі;
Calendar – календарні дані та ознака святкового дня.

Логіка полів :
is_holiday
TRUE – дата є святковим днем;
FALSE – дата є звичайним днем.

Файли проєкту
схема.png – схема структури даних;
forecast_dataset.xlsx – тестові дані

для кожної таблиці згенеровано 100 тестових записів.
